How live publishing works
The portal writes media changes to your GitHub repository.
Fixed filenames: image replacements use the existing slot name such as 01.jpg. A new image uploaded to Wedding slot 01 replaces images/wedding/01.jpg. After the GitHub commit, Vercel's connected production deployment rebuilds the live website automatically. For large videos, the video is uploaded directly to Vercel Blob and the public site receives the new video URL through the GitHub media manifest.
Safety rule
This portal controls media only. It does not redesign the public site.
